# Неделя 3 · этап 3 — приёмка на чужом ящике

Общий синтетический ящик для всех команд. Формат тот же, что в задании недели (ящик после
отпуска → план на день), компания — другая, вымышленная. Данные синтетические, все имена,
компании и адреса выдуманы, домены — `*.example`.

Прогоните свой инструмент на этом наборе **без правок** и положите ответы на пять контрольных
вопросов в README рядом с планом в своём репозитории.

## Легенда

ООО «Стенд Форма» — небольшое бюро, проектирует и строит стенды для компаний на выставках.
Марина Костина, операционный директор, вернулась из отпуска. Отпуск: 05.10.2026 (пн) –
18.10.2026 (вс). Первый рабочий день — **понедельник, 19.10.2026**. Это и есть «сегодня» для
плана: план нужен на сегодня, 19.10.2026.

Почта владелицы ящика: `marina@stend-forma.example`.

## Что в наборе

| [`inbox/`](inbox/) | 40 входящих писем `E01`–`E40`, 05.10–18.10.2026. По файлу на письмо: `E01.md` … `E40.md` |

| [`sent/`](sent/) | 10 писем, которые Марина отправила **до** отпуска, `S01`–`S10`, 30.09–02.10.2026. По файлу на письмо |

| [`chat.md`](chat.md) | рабочий чат команды «Стенд Форма», 80 сообщений `C001`–`C080`, 05.10–18.10.2026. Строка: `[id] YYYY-MM-DD HH:MM Имя: текст` |
| [`chat.jsonl`](chat.jsonl) | тот же чат, одна строка JSON на сообщение |
| [`notes.md`](notes.md) | рабочая заметка Марины, написанная перед отпуском (02.10.2026) |

### Формат письма (`inbox/*.md`, `sent/*.md`)

Шапка из шести полей, потом разделитель `---`, потом текст письма:

```
id: E07
from: Виктор Горин <v.gorin@elektrostend.example>
to: Марина Костина <marina@stend-forma.example>
cc: 
date: 2026-10-07 09:05
subject: Смета на электромонтаж АгроЛидер + акт за сентябрь
---

(текст письма)
```

В `inbox.jsonl` / `sent.jsonl` те же поля в одной строке JSON: `id`, `at` (ISO-дата и время),
`from`, `to`, `cc`, `subject`, `body`.

## Пять контрольных вопросов

Дословно из текста этапа:

1. Что горит сегодня.
2. Какое обещание просрочено.
3. Какое решение позже отменили в переписке.
4. Что не требует действий.
5. Где заметка владельца расходится с фактами.

## Как сдать

- Прогоните свой инструмент (тот же, что собирал план на этапах 1–2) на этом наборе — **без
  правок данных и без правок инструмента под эти данные**.
- Ответы на пять вопросов — в README рядом с планом в своём репозитории, по одному пункту на
  вопрос.
- У каждого ответа — ссылка на источник (`id` письма или сообщения чата из этого набора:
  `E01`–`E40`, `S01`–`S10`, `C001`–`C080`, или `notes.md`).
- Отдельной строкой — сколько ручных правок понадобилось (ожидаемый ответ: 0).

Ключ ответов у ведущих, участникам не публикуется.
